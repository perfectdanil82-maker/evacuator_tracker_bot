# Evacuator Bot

## Запуск на Railway

1. Залей папку на GitHub (новый репозиторий)
2. Зайди на railway.app → New Project → Deploy from GitHub
3. Выбери репозиторий → Deploy
4. Готово — бот работает 24/7

## Что нужно поменять в bot.py

- PRODAMUS_LINK — вставь ссылку на оплату из Prodamus

## Файлы данных

- used_codes.json — список выданных кодов (создаётся автоматически)
- user_codes.json — какой код выдан какому пользователю

## Добавить новые коды

Добавь строки в список CODES в bot.py
